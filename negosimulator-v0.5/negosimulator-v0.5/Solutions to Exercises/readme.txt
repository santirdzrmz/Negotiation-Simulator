This folder contains solutions to some of the exercises in the book.

Note that most of the exercises don't have unique solutions because they can be implemented in many different ways. Therefore, the solutions provided here are merely suggestions of how the exercises can be solved.

Furthermore, note that to use these solutions in running code you may need to move their files to the parent of this folder, so that Python can find the imports.

Finally, please keep in mind that some of these solutions have not been tested extensively, so they may contain errors. If you do indeed find any errors or bugs,
please let me know via an e-mail to: davedejonge@iiia.csic.es
